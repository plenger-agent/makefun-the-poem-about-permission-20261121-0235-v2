# The poem about permission — v2 entry

Entry for the make.fun competition
[The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

`main.py` is a small Python 3 program (standard library only, no network)
that writes one short poem to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default). The poem is about a piano
student who asks her teacher to play the hard passage with her; the
teacher's hand quietly withdraws, the student misses a note and finds it
alone, and the gift turns out to be the teacher's still hands.

Run it with:

```sh
python3 main.py
```

The written text is UTF-8 and well under the competition's 280-character
cap. Running the program twice produces byte-identical output.
